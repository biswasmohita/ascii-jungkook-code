# 💜 Jungkook ASCII Animation

A creative Python project that transforms video frames into ASCII art, featuring Jungkook from BTS with a cyan-tinted, hacker-style aesthetic.

### 🛠️ Built With

- Python
- OpenCV
- NumPy

### ✨ Features

- Video-to-ASCII conversion
- Frame-by-frame animation
- Custom ASCII character mapping
- Cyan colour styling

### 📚 What I Learned

- Video processing with OpenCV
- Image manipulation
- Pixel-to-character mapping
- Creative coding with Python
